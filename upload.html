Đăng demo

Thả file HTML, bấm Deploy, khoảng 1–2 phút sau có link xem demo trên GitHub Pages để gửi khách.

1

Kết nối GitHub

Cách lấy token (làm một lần, khoảng 1 phút)
  1. Mở github.com/settings/personal-access-tokens/new.
  2. Token name: kho-demo. Expiration: 90 ngày hoặc lâu hơn.
  3. Resource owner: chọn organization data-service-base.
  4. Repository access: Only select repositories → chọn data-service-demos.
  5. Permissions → Repository permissions: Contents = Read and write. Thêm Actions = Read-only để trang báo lỗi build nếu có.
  6. Bấm Generate token, copy và dán vào ô trên.

Nếu GitHub báo token đang chờ duyệt, chủ organization vào Settings → Personal access tokens → Pending requests để duyệt.
